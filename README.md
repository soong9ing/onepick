# 원픽 OnePick 💘

> 여러 명 말고, **딱 한 사람.**
> 프로필을 만들고 원하는 키워드를 고르면, 나와 가장 잘 맞는 단 한 명을 추천해 주는 소개팅 웹앱입니다.

## 주요 기능

| 단계 | 내용 |
|---|---|
| 1. 회원가입 / 로그인 | 이메일 + 비밀번호 (비밀번호는 SHA-256 해시로 저장) |
| 2. 프로필 설정 | 닉네임, 나이, 성별, 직업, 지역, MBTI, 한 줄 소개, 찾는 상대 성별·나이 범위, 나를 표현하는 키워드 3~8개 |
| 3. 원하는 키워드 선택 | 성격·취미·라이프스타일·연애 스타일 중 상대에게 바라는 키워드 3~8개 |
| 4. 원픽 추천 | 궁합 점수 1위 **한 명**만 보여 주고, 왜 잘 맞는지 이유를 설명 |

추가로 `관심 보내기`, `다른 사람 추천받기`(본 사람 제외 후 다음 1위), 프로필·키워드 수정 기능이 있습니다.

## 매칭 알고리즘 (`match.js`)

100점 만점으로 계산합니다.

| 항목 | 배점 |
|---|---|
| 내가 원하는 키워드를 상대가 가진 비율 | 50 |
| 상대가 원하는 키워드를 내가 가진 비율 (쌍방향) | 20 |
| 서로의 키워드 공통점 | 15 |
| 지역 (같은 지역 8 / 인접 지역 4) | 8 |
| MBTI 궁합 (E/I 보완, N/S 일치 등) | 7 |

- **항상 매칭**: 어떤 키워드를 골라도 반드시 한 명이 추천됩니다. 성별·나이 조건이 안 맞으면 탈락 대신 40% 감점되어, 조건이 맞는 사람이 항상 먼저 추천돼요
- 추천을 모두 넘겨 보면 처음부터 다시 추천합니다
- 상대가 원하는 나이대에 내가 없으면 15% 감점
- 위 점수(0~100)는 순위를 매길 때만 쓰고, 화면에 보이는 궁합 점수는 **90~100%** 로 환산해서 보여 줍니다

## 실행 방법

빌드 과정 없는 순수 HTML/CSS/JavaScript 프로젝트입니다.

```bash
# 그냥 index.html 을 브라우저로 열어도 되고, 로컬 서버로 열어도 됩니다
npx serve .
```

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만든다 (예: `onepick`)
2. 이 폴더의 파일을 올린다
   ```bash
   git remote add origin https://github.com/<내아이디>/onepick.git
   git branch -M main
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 선택 후 Save
4. 잠시 후 `https://<내아이디>.github.io/onepick/` 에서 접속

## 파일 구조

```
onepick/
├── index.html   # 화면 뼈대
├── style.css    # 디자인
├── images/     # 샘플 회원 프로필 사진 (원본 구도, 긴 쪽 1000px)
├── data.js      # 키워드 목록, 지역, 샘플 회원 12명
├── match.js     # 궁합 점수 계산 / 1위 추천
└── app.js       # 라우팅, 가입·로그인, 프로필, 키워드, 결과 화면
```

## 한계와 다음 단계

- 지금은 데이터가 **브라우저 localStorage**에만 저장돼서, 다른 사람의 기기에서 가입한 회원끼리는 서로 보이지 않습니다. 추천 대상은 샘플 회원 12명 + 같은 브라우저에서 가입한 회원입니다.
- 실제 서비스로 만들려면 Firebase / Supabase 같은 백엔드를 붙여 회원 정보를 서버에 저장하면 됩니다. `getUsers()`, `saveUsers()` 함수만 서버 호출로 바꾸면 나머지 로직은 그대로 쓸 수 있어요.
- 샘플 회원 12명은 모두 이름·성별·나이가 같은 가상 프로필(성수경 / 여 / 만 21세)이고, 사진·직업·지역·MBTI·소개·키워드가 서로 다릅니다. 사진은 `images/` 폴더, 사진·직업 목록은 `data.js`의 `SAMPLE_DETAILS`에 있어요. 기본값은 `data.js`의 `SAMPLE_BASE`에서 바꿀 수 있어요.
